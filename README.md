## Featured projects

### [FANA — AI lead qualification & HubSpot automation](https://github.com/MahmoudElnahal/fana)
One n8n workflow that takes real-estate leads from Telegram, WhatsApp, the website and Meta/Google forms, qualifies them in Saudi Arabic with an AI agent, scores them with transparent rules (P1/P2/P3), and syncs HubSpot contacts and deals without duplicates.
`n8n` `LLM agent` `HubSpot` `Google Sheets` `JavaScript`

### [AI Agents & Intelligent Automation](https://github.com/MahmoudElnahal/ai-agents-automation)
Two agents on two platforms, chained end to end: an n8n agent turns farm sensor data into an alert or report email, and a UiPath agent reads the inbox, triages each email and files a structured report to Google Drive.
`UiPath Agent Builder` `n8n` `LangChain` `Gmail` `Google Drive`

### [ATS — LLM resume parser & job matcher](https://github.com/MahmoudElnahal/ATS)
Prototype of the applicant tracking system built for the Ministry of Labor of Oman: parses PDF resumes into structured data with GPT-4o, scores each candidate against a job description, and returns a ranked shortlist with a written verdict. Ships as a Streamlit app and a FastAPI service.
`Python` `OpenAI` `FastAPI` `Streamlit` `Pydantic`
